# Librio

## Tổng quan

Librio là một ứng dụng quản lý thư viện, giúp thủ thư quản lý sách, người dùng, và đơn mượn và giúp người dùng xem sách,
mượn sách, quản lý sách sách đã mượn và trả sách. Ứng dụng được xây dựng bằng JavaFx, Fxml và sử dụng cơ sở dữ liệu
MySQL.

## Cài đặt

### Điều kiện tiên quyết

* JDK 21
* MySQL

### Cách chạy ứng dụng

1. Clone repository

```sh
git clone https://github.com/thaihoc1310/Librio.git
```

2. Mở project bằng IntelliJ IDEA
3. Vô Appication và chạy ứng dụng

## Tính năng

* Đăng ký
* Đăng nhập
* Quên mật khẩu

### Người dùng

* Xem sách
* Mượn sách
* Xem sách đã mượn
* Trả sách
* Đánh giá sách
* Tìm kiếm và lọc sách theo thể loại, ngôn ngữ, rating, ...
* Gợi ý khi tìm kiếm sách
* Gợi ý các thể loại, các sách phổ biến ,... trên trang chủ
* Nhận thông báo khi sách đã mượn sắp hết hạn, đã quá hạn
* Tìm kiếm sách đã mượn
* Cập nhật thông tin cá nhân, Đổi mật khẩu

### Thủ thư

* Thêm sách, người dùng, đơn mượn
* Xem sách, người dùng, đơn mượn
* Cập nhật sách, người dùng, đơn mượn
* Xóa sách, người dùng, đơn mượn
* Tìm kiếm sách, người dùng, đơn mượn
* Thêm sách qua API Google Books
* Xem thống kê thể loại, đơn mượn theo tháng
* Cập nhật thông tin cá nhân, Đổi mật khẩu
