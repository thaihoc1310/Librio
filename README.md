# Librio

***

## Overview

Librio is a library management application that helps librarians manage books, users, and borrowing transactions, as
well as allowing users to view books, borrow books, manage borrowed books, and return books. The application is built
using JavaFX, FXML, and MySQL database.

## Installation

### Prerequisites

* JDK 21
* MySQL

### How to Run the Application

1. Clone the repository

```sh
git clone https://github.com/thaihoc1310/Librio.git
```

2. Open the project in IntelliJ IDEA
3. Go to Application and run the app

## Features

* Register
* Login
* Forgot password

### Users

* View books
* Borrow books
* View borrowed books
* Return books
* Rate books
* Search and filter books by genre, language, rating, etc.
* Suggestions when searching for books
* Suggestions for genres, popular books, etc., on the homepage
* Receive notifications when borrowed books are expire or overdue
* Search borrowed books
* Update personal information, change password

### Librarians

* Add books, users, and borrowing transactions
* View books, users, and borrowing transactions
* Update books, users, and borrowing transactions
* Delete books, users, and borrowing transactions
* Search books, users, and borrowing transactions
* Add, search books via the Google Books API by by genre, language, rating, etc.
* View category statistics and borrowing transactions by month
* Update personal information, change password
